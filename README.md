# 情侣相册项目部署说明

## 环境要求
- Node.js 16.x 或更高版本
- npm 8.x 或更高版本
- Windows Server 环境

## 部署步骤

1. 解压部署包到目标目录
2. 运行 `start.bat` 脚本，该脚本会自动：
   - 安装前端依赖
   - 构建前端项目
   - 安装后端依赖
   - 启动后端服务

## 目录结构
```
couple-album/
  ├── client/          # 前端项目
  ├── server/          # 后端项目
  ├── albums.json      # 相册数据
  ├── users.json       # 用户数据
  └── start.bat        # 启动脚本
```

## 注意事项
- 确保服务器的 80 端口未被占用
- 确保有足够的磁盘空间（建议至少 1GB）
- 首次启动可能需要几分钟时间来安装依赖

## 访问应用
启动成功后，可以通过以下地址访问应用：
- 前端页面：http://localhost:3000
- 后端接口：http://localhost:3001

## 故障排除
如果遇到启动问题：
1. 检查 Node.js 版本是否正确
2. 检查端口是否被占用
3. 检查 start.bat 是否有执行权限
4. 查看日志文件排查具体错误
